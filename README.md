# SENKRON AI Assistant

## Kurulum
1. `requirements.txt` dosyasındaki bağımlılıkları yükleyin:
```
pip install -r requirements.txt
```

2. `main.py` dosyasını çalıştırın:
```
uvicorn app.main:app --reload
```

3. `YOUR_OPENAI_KEY` ve `YOUR_MONGODB_CONNECTION_URI` alanlarını kendi bilgilerinizle doldurun.

4. Railway'e bu repoyu bağlayın ve otomatik olarak deploy edin.
